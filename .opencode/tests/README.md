# Локальные проверки Confluence-плагина

Node.js 22.13+; внешние пакеты не нужны. Из корня репозитория:

```powershell
node --experimental-vm-modules --test .opencode/tests/confluence-pii.test.mjs .opencode/tests/confluence.test.mjs
```

Тесты проверяют PII-маскирование и контракт инструмента OpenCode V2. SDK, чтение
настроек, окружение и `fetch` подменены: реальные credentials не читаются,
HTTP-запросы и публикация Jira/Qase не выполняются. Предупреждения об experimental
VM/TypeScript API ожидаемы на версиях Node, где эти API ещё экспериментальные.

Маскирование эвристическое: неподписанные секреты и номера из одних цифр нельзя
надёжно отличить от обычного текста и ID. Безопасные ссылки и XHTML сохраняются;
значения PII в ссылках/атрибутах намеренно заменяются маркерами.
